一、什麼是憑證、HTTPS、HTTP、Port？

1.憑證

網路憑證通常指的是 SSL/TLS 憑證，用來證明網站的身分，並協助建立加密連線。
  • 驗證身分：確認你連上的網站是真的，不是假冒的網站。
  • 資料加密：把傳送的密碼與個資加密，防止被駭客偷看或竄改。

2.HTTP

HTTP 是一種網頁通訊協定，規定瀏覽器與伺服器之間如何傳送網頁請求與回應。
  • 通常使用 TCP Port 80。
  • HTTP 本身不提供 TLS 加密。
  • 如果傳輸內容沒有另外加密，可能被網路上的其他人攔截查看或竄改

3.HTTPS

加上了「憑證」加密的 HTTP。瀏覽器與伺服器之間的通訊會被加密成亂碼，就算被攔截也無法解密，確保資料傳輸安全。

4.Port

Port 可以想成電腦上的「服務入口編號」。 一台電腦可能同時執行很多網路服務，Port 可以協助作業系統把收到的連線交給對應的服務。

二、Inbound、Outbound 防火牆是什麼？怎麼設定？

  • 防火牆是一種網路安全機制，可以根據規則決定哪些網路流量允許通過、哪些流量拒絕。
  • Inbound（入站）：進入電腦或網路的流量。
  • Outbound（出站）：離開電腦或網路的流量。
防火牆設定：無論是 Windows 內建防火牆、雲端平台 (如 AWS Security Group) 還是企業硬體防火牆，設定邏輯皆為：
  1. 方向： 選擇是針對 Inbound 還是 Outbound 制定規則。
  2. 來源與目的地 IP： 誰可以連進來？（例如設定 0.0.0.0/0 代表允許全世界，或指定只有老闆家裡的 IP 能連線）。
  3. Port 與協定： 開放哪個通道？（例如開放 TCP 協定的 Port 22 用於遠端管理）。
  4. 動作： 允許 (Allow) 或 拒絕 (Deny)。

三、什麼是 CIDR？

CIDR (無類別域間路由) 是一種用來分配 IP 地址與表示「網段」的標準寫法。
表示法範例： 192.168.1.0/24
原理： IPV4 是由 32 個位元 (bits) 組成。後面的 /24 代表前 24 個位元被鎖定為「網段範圍」，剩下 8 個位元 (32 - 24 = 8) 則用來分配給這個網段內的設備。

四、DNS、IP、域名與 URL

  • DNS：將域名解析為 IP 位址的系統
  • IP：網路通訊使用的位址
  • 域名：容易記憶的網站名稱，例如 google.com
  • URL：包含了連線方式、域名、路徑與檔案等的完整網址

五、URL解析

例：https://www.ncnu.edu.tw:1234/class/upload.php?file=abc

將其分為：[https://][www.ncnu.edu.tw][:1234/][class/][upload.php?][file=abc]
分隔區段 結構名稱 具體說明
[https://] 通訊協定 告訴瀏覽器要使用「加密的安全超文字傳輸協定」來連線。
[www.ncnu.edu.tw] 完整網域 網站的文字伺服器名稱（此處為國立暨南國際大學全球資訊網）。
[:1234/][cite: 1] 連接埠與路徑起頭 指定連接伺服器的 1234 號通道，後方的 / 代表進入網站的根目錄。
[class/] 資料夾路徑 伺服器上的特定分類目錄（課程或類別資料夾）。
[upload.php?] 網頁程式與參數起頭 負責處理要求的網頁程式檔案，? 符號代表後面開始帶入引數。
[file=abc] 查詢變數 傳給該程式的具體資料。變數名稱為 file，其帶入的數值為 abc。
